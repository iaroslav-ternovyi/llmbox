# Security

Please report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository
(<https://github.com/iaroslav-ternovyi/llmbox/security/advisories/new>), not in a public issue.

In scope: the `llmbox` program and its installer (`install.sh`), the results server (`llmbox serve`, `deploy/`), and the
site. Especially welcome: anything that runs code from a submitted result outside the sandbox (`deploy/sandbox.sh`),
gets around sign-in or erasure, or makes `install.sh` or `llmbox update` install something other than this repository.

You will get an answer within a week. Fixes are released as soon as they are ready and credited unless you prefer not.
