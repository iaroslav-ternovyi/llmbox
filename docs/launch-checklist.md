# llmbox: готовность к запуску

Ворота перед публичным запуском: пока здесь есть открытые пункты «обязательно», сервис не запускается.
Составлено 2026-10-01 по аудиту кода и двум исследованиям (чек-листы запуска похожих сервисов, аналитика без cookies
для ЕС); источники в конце. Обозначения: ✅ сделано · 🔧 делаю я · ❓ нужно твоё решение · 🔑 нужен твой аккаунт.

## 1. Измерение (без этого запуск вслепую)

Цели первых 30 дней (утверждены 2026-10-02):
- **Покрытие:** хотя бы 30 из 65 «машин» выбора железа на сайте получили замер.
- **Объём:** хотя бы 100 замеров скорости с 50 машин (разные id установки).
- **Качество:** хотя бы 10 тестов качества от вошедших.
- **Карточки:** хотя бы 10 страниц прогонов, на которые пришли из соцсетей (нижняя оценка), плюс ручной поиск.
- **Возврат:** прямые заходы и чтение RSS в 3–4 недели не меньше 30% от недели запуска (верхняя оценка: приложения
  не всегда передают источник).

Главная метрика — замеры с нового железа: ради них сервис.

| Пункт | Статус |
|---|---|
| Аналитика сайта без cookies: посещения, источники, выбор железа, «скопировал команду», вход | ✅ GoatCounter на нашем сервере (решено 2026-10-01); счётчик и события проверены на настоящем GoatCounter 2.7.0 · 🔑 включить на сервере |
| Воронка без телеметрии CLI: скачивания install.sh и запросы списка моделей по версии (Pages Function → API GoatCounter), отправки и входы из базы | ✅ API GoatCounter проверен · 🔧 Pages Function проверить на первом деплое · 🔧 клоны GitHub (ежедневный архив) |
| Публичная панель статистики (довод доверия для этой аудитории) | ✅ решено · 🔑 включить в настройках GoatCounter |

## 7. CLI и установка

| Пункт | Статус |
|---|---|
| Путь новичка проверен вживую (≈3 мин до работающей модели) | ✅ |
| Громкое предупреждение, если модель работает на CPU (главная жалоба на LocalScore) | ✅ |
| Сообщение о новой версии | ✅ |
| Windows (WSL2), AMD, Mac — проверить на настоящем железе (3–5 человек) | ❓ кто |
| Mac M2 Max 32 GB (Metal), 2026-10-02: `llmbox test` ставит Metal-сборку и меряет. На Metal внимание на глубине упирается в вычисления, а не в чтение KV: формула завышала скорость на 32k в 2–2,5 раза. Добавлен член Metal (llama-bench, 4 модели, ширина головы 128/256/512), теперь на 16–32k в пределах 15% (tests/test_metal_depth.py). Mac меряется только на 32k: префилл 80k занимал 8 из 16 мин шага скорости. Связанный выход (Gemma, Llama 3.2: нет output.weight, таблица эмбеддингов читается целиком каждый токен) теперь учтён: Gemma 3 на CUDA k2 1,14→1,02, на Metal ошибка 27%→17%. Остаётся: короткий чат Gemma 4 E-моделей (таблицы per-layer) 111 против 71 ток/с | ⚠️ Gemma 4 E на Metal |
| PyPI `llmbox-bench`, после первого релиза установка с PyPI | 🔑 |
| Удаление описано (сайт, install.sh) | ✅ |
