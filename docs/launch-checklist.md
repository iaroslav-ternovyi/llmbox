# llmbox: готовность к запуску

Ворота перед публичным запуском: пока здесь есть открытые пункты «обязательно», сервис не запускается.
Составлено 2026-10-01 по аудиту кода и двум исследованиям (чек-листы запуска похожих сервисов, аналитика без cookies
для ЕС); источники в конце. Обозначения: ✅ сделано · 🔧 делаю я · ❓ нужно твоё решение · 🔑 нужен твой аккаунт.

## 1. Измерение (без этого запуск вслепую)

Цели запуска (предложение, утвердить): за первые 30 дней 1000 посетителей, 100 установок, 30 отправленных замеров
скорости с разного железа, 10 тестов качества от вошедших. Главная метрика — замеры с нового железа: ради них сервис.

| Пункт | Статус |
|---|---|
| Аналитика сайта без cookies: посещения, источники, выбор железа, «скопировал команду установки» | ❓ GoatCounter на нашем сервере (рекомендую) / Cloudflare Web Analytics / Umami Cloud |
| Воронка без телеметрии CLI: скачивания install.sh (Pages Function), запросы списка моделей по версии (User-Agent), клоны GitHub, отправки и входы из базы | ✅ User-Agent с версией · 🔧 остальное после выбора аналитики |
| Публичная панель статистики (довод доверия для этой аудитории) | ❓ |

## 2. Наблюдаемость

| Пункт | Статус |
|---|---|
| Ошибки JS на сайте: свой эндпоинт /api/v1/err (сообщение, страница, сборка; без IP; 30 дней) | 🔧 |
| Ошибки CLI: понятное сообщение, детали в ~/.llmbox/last-error.txt, `llmbox bug` — готовый issue, отправляет сам человек | ✅ |
| Доступность API и свежесть сайта: Better Stack free (проверка /api/v1/health каждые 3 мин, сигнал после публикации) | 🔑 |
| Логи сервера: journald, IP маскируются в Caddy, срок хранения | 🔧 |
